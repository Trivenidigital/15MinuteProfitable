5. Bregman Divergence / Information-Theoretic Framework

NEW FEB 8 Comprehensive mathematical framework integrated across all strategies. All features behind config toggles (default OFF). Zero behavior change unless explicitly enabled.

Why Bregman divergence? Ad-hoc confidence calculations treat probability space as Euclidean. A 5-cent mispricing at 0.50 is fundamentally different from 5-cent at 0.95, but Euclidean distance treats them the same. KL divergence (a Bregman divergence) correctly weights mispricings across the probability simplex.

Phase 1: Divergence Utility Module

IMPLEMENTED

File: src/utils/divergence.py (~150 lines) + tests/unit/test_divergence.py (~120 lines)

Pure math module with no side effects:

  • kl_divergence_binary(p, q) — D_KL(p||q) for binary distributions
  • simplex_project(yes_ask, no_ask) — Normalize to probability simplex (handles overround)
  • market_mispricing_score(yes_ask, no_ask) — Returns {p_fair, kl_divergence, kl_reverse, jensen_shannon, overround}
  • divergence_scaling_factor(kl) — Piecewise linear map for Kelly scaling (0.5x–2.0x)
  • compute_return_correlation(price_series, window) — Pearson correlation matrix from spot histories
  • bregman_projection(observed, correlation_matrix, n_iter) — KL projection onto correlation-consistent set
  • divergence_exit_signal(entry_kl, current_kl, direction, ratio) — Exit when mispricing has closed
